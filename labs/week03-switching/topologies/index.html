Export w03-a1-mac-table before the week starts

Three activities depend on it, and it is the week's most-rebuilt topology. A student who breaks it during A2 should not lose A4 as well.

Note that A2 requires PC1 to be swapped from VPCS to an OL9 PC. Either export both states (w03-a1-mac-table and w03-a1-mac-table-ol9pc1), or export the OL9 version and let A1 run on it — A1 works fine with an OL9 PC in place of a VPCS one, it just costs 512 MB more.

w03-a5-stp — export the working state

Export it with one inter-switch link, STP off. That is the activity's starting point. Do not export it mid-storm.

A6 needs the OVS appliance imported first

Docker on the GNS3 server is a prerequisite (../../../gns3-lab0-switching.md §D0). A portable project referencing a Docker template that is not installed will import and then fail to start, which is a confusing way to discover a missing prerequisite. Check §D0 before distributing.
